# 详情页屏次库与版式规则

## 屏次库（按需挑选 8 屏以上）
按叙事顺序，不是每屏都要：
1. **首屏钩子/定调**：商品全貌或场景大图 + 一个核心购买理由。只表达一个主张。
2. **痛点对比屏**：左右/上下分屏，暗调痛点 vs 亮调优势，叉号对勾。
3. **核心卖点屏**：最大卖点图解、局部放大、Bento 数据卡片。
4. **原料/工艺屏**：原料特写、手工/工艺过程、匠人感。
5. **材质/细节微距屏**：极近距离拍纹理、肌理、断面。
6. **口感/体验屏**：食品用高速动态（掰开、飞溅、流心、热气）；其他品类用使用瞬间。
7. **味道/成分克制屏**：配料、调味、成分微距，强调"干净/刚好"。
8. **多场景屏**：四宫格/上下拼接生活方式，同一产品贯穿。
9. **商品参数屏**：图标化 Bento 卡片，不是表格罗列。配料表/净含量/保质期/储存方式。
10. **信任/品牌收尾屏**：场景静物 + 品牌情感 slogan + 召唤。

## 品类权重（先讲什么）
- 食品：原料 → 口感/酥脆 → 配料干净 → 场景 → 规格。
- 美妆：成分 → 质地肤感 → 使用步骤 → 效果边界。
- 3C：参数 → 性能对比 → 结构 → 场景。
- 服饰：上身 → 尺码 → 材质 → 搭配。
- 母婴：安全材质 → 场景 → 清洁。

## 版式呼吸感（必须穿插，禁止每屏雷同）
- 居中英雄构图（首屏、收尾）
- 左右分栏对比（痛点）
- Bento 网格卡片（卖点、参数）
- 微距破框/斜角（细节、口感）
- 四宫格生活方式（场景）
- 纯文字色块过渡屏（可选）

## 运镜变化（避免每屏证件照）
- 远景全貌：首屏、收尾。
- 中景交互：手捧原料、翻炒、使用动作。
- 近景微距：肌理、断面、调料颗粒。

## 全局视觉锚点（全套统一）
- 主色板（如食品：暖金/棕褐/米白）。
- 主光源方向（暖侧逆光）。
- 字体气质（标题书法感或粗宋，正文细黑/细宋）。
- 产品外观锚点（来自用户产品图）。
