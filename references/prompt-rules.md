# 即梦提示词与出图规则

## 即梦/AI 提示词硬规则
- 全程中文。
- 待渲染画面文字用中文双引号“”圈出，如“一口锅巴香”。
- 除引号内文案外，**不得出现零宽字符**。
- 标点只用顿号、逗号、句号；不用冒号、分号、感叹号、破折号、emoji。
- 单条提示词 ≤ 750 字。
- 不写比例、像素、模型名、参考图编号到 prompt 之外的位置（参考图编号用 [img0]）。

## 每屏提示词结构（一段连贯中文）
1. 开头锚定产品：以[img0]中的产品为主体，严格保留其（颜色、形状、纹理、质感）外观特征。
2. 画面类型与构图：竖版电商详情页某屏 + 版式骨架。
3. 背景与道具：具体到材质、颜色、虚化程度。
4. 光影：方向、色温、明暗。
5. 文字：逐字写出，位置、字体气质、字号层级、颜色。
6. 整体色调收束。

## 出图工具参数
- 工具：`image_edit`（有产品参考图时）。
- `image_reference_url_list`：产品图 URL（[img0]）。
- 比例 9:16 → width 约 1440，height 约 2560。
- 一次并行不超过 10 屏。

## 食品品类视觉要点
- 食欲感高光、酥脆/流心动感（飞溅、掰开、热气）。
- 高饱和暖色，极清微距。
- 字体可活泼粗圆体；走乡土怀旧风时用书法感大字。

## 文字与事实纪律
- 所有画面文字必须逐字写进 prompt，禁止"待补充""XX"。
- 价格、折扣、销量、功效百分比、认证编号、专家背书：用户没给就不写。
- 参数屏缺真实数值时写"见包装"，不编数字。
